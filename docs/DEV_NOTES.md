## Why I made Wallpaper Color

I was missing some features from Windows, since I decided to switch to CachyOS, so I don't have to deal with Microslop's BS, I was basically configuring the OS and stuff and it kept getting on my nerves that I had to use predetermined colors from OpenLinkHub, instead of having the colors get dynamically replaced like you see in Wallpaper Engine (which, for the record, has this functionality since it can get integrated with the iCUE software).

So basically I said f#ck it, I'm gonna make my own, and so I did.  To be fair, I didn't expect anything from this, so I just used Claude to see if I could make something interesting out of it, and so I did. This started as a completely vibecoded project, but I didn't understand a thing, so I decided to give this an actual architecture so it's not just a weird vibecoded functionality.

And I think it's gone pretty well, I'm very happy with it and I use it on a daily basis, since it looks cool AF.

I have no experience creating things like drivers or stuff, so, if you see that the architecture of the program resembles an API too much, well, that's because it does, since I have no idea of how the architecture for something like this should look, so this may be a side quest I make once I understand how to program better in C++, or, at all, for the record.

Like I said, I'll be maintaining this project myself, as I get better at using C++, since I think it's a pretty interesting language, and might teach me a lot about how computers actually work (even though I should know that conceptually, I presume).

That's it, I'm definitely not going back to Windows, so I'll probably do more stuff like this for Linux in the future.
